Guides

Run the deploy

Lock the tracker, work through the runlist, and make the go or no-go calls.

Before you start

  1. The person running the deploy chooses Extensions > DeployLogs > Turn on the audit log, once.
  2. They click Lock or unlock on Overview, or choose Lock for the run. Every tab is locked so only they can edit. Everyone else can still see every tab.

Work through the steps

  1. Take the next step whose Can start? is Ready.
  2. Set Status to In progress. Started fills in.
  3. When it is done, set Status to Done. Finished and Actual hours fill in. Fill in Value handed over if the step hands something over.
  4. If something goes wrong, add it to Issues.

Watch the overview

  • On track? compares the projected finish with the deadline.
  • Latest safe time to keep going is the deadline minus the work left, the planned waits and the time to roll back everything.
  • Safe to keep going? turns to No once there is no longer time to roll back if something fails.

Gates

At the end of each stage, each team listed on Gates makes its Call: Go or No-go. The stage's Gate on the Stages tab shows Go once every listed team has said Go, and No-go if any has.

Roll back, don't rescue

If a stage gets a No-go, or a step fails and there is no safe fix, follow the step's Rollback steps and the Rollback plan. A rollback that was planned and practiced is safer than a fix invented at 2am.

After the run

Click Lock or unlock again to unlock, so teams can update the plan.
