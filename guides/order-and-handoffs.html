Guides

Order, waits and handoffs

Put every team's steps in one order, and pass IDs from one team to the next.

Run order

Give each step a Run order: 1, 2, 3, across every team. Sort the Steps tab by Run order to see the runlist.

Waits for

In Waits for (IDs), list the steps that must be done first, separated by commas: D-01, D-04. Often it is another team's step.

Can start? then shows:

  • Ready nothing left to wait for.
  • Waiting on D-04 (Billing) the steps not yet Done or Skipped, and their team.
  • Check order: waits for a later step the step waits for a step with a later run order. Fix the order.

If someone sets a waiting step to In progress, a "Still waiting" message names what it is waiting on.

Handoffs

  1. On the step that creates something the next team needs, write what it is in Hands over: "Invoice template IDs, for the integration release".
  2. On the day, the owner puts the real value in Value handed over.
  3. The waiting step shows it in Received from earlier steps: "D-04: Invoice template IDs = INV-2207". Until then it says "(not handed over yet)".

Overview counts steps that are Done but handed nothing over.
